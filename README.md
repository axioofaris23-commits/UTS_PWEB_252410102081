## Penjelasan Aplikasi
**Kopi Ilkom** adalah aplikasi web manajemen internal warung kopi berbasis framework **Laravel**. Web ini digunakan oleh administrator untuk mengelola data produk kopi, kategori, harga, stok, serta melihat statistik ringkas toko dan informasi profil pengelola.

## Fitur Utama
1. **Autentikasi (Login & Logout):** Proteksi halaman internal menggunakan Session dan Middleware.
2. **Dashboard:** Menampilkan statistik total menu, total stok, dan daftar produk terlaris.
3. **Pengelolaan Menu:** Rendering data array produk kopi ke dalam tabel interaktif.
4. **Profil Admin:** Menampilkan informasi hak akses dan detail outlet administrator.

## Teknologi yang Digunakan
- **Framework:** Laravel 11 / 10
- **Styling:** Tailwind CSS / Blade Templating
- **Arsitektur:** MVC (Model-View-Controller)
